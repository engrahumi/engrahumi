# البطل الصغير 🎮

لعبة منصات (قفز وجري) لأجهزة أندرويد، البطل فيها هو الطفل اللي بالصورة.

## طريقة اللعب
- ◀ ▶ للحركة، ▲ للقفز (اضغط مطوّل لقفزة أعلى).
- اجمع العملات واكسر صناديق الهدايا من تحت (بعضها فيها قلب = حياة إضافية).
- انزل على الوحش البنفسجي عشان تقضي عليه — بس الوحش الأخضر أبو الشوك لا تنزل عليه!
- وصل للعلم والبيت بآخر المرحلة. كل مرحلة أطول وأصعب، وكل 50 عملة = حياة.

## تحميل ملف APK
كل `push` يبني ملف `LittleHero.apk` تلقائيًا عن طريق GitHub Actions:
- من صفحة **Releases** بالمستودع، أو
- من **Actions → Build APK → Artifacts**.

نزّل الملف على التلفون وثبّته (فعّل "التثبيت من مصادر غير معروفة").

## تجربة سريعة بالمتصفح
افتح `app/src/main/assets/index.html` بأي متصفح (الأسهم + المسافة).
